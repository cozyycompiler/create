# 🌷 Cozy Journal

A simple and aesthetic Java console program that displays
daily journal entries, moods, and thoughts.

## ✨ About the Project

Cozy Journal is a small Java project created to practice
Object-Oriented Programming concepts while making a cute
and relaxing console application.

Each journal entry contains:

- 📅 Day
- 💗 Mood
- 💭 Thought

## 💻 Features

- 🌷 Create journal entries
- 😊 Store different moods
- 💭 Display personal thoughts
- 📋 Store multiple entries using an array
- 🔄 Display entries using a loop
- ✨ Uses Java classes and objects
